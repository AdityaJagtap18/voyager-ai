# 2. PRODUCT VISION

## 2.1 Product identity

**Voyager AI — An Open-Source AI-Powered Travel Planning and AI Engineering Platform.**

Voyager solves a real-world problem: helping people research, plan, optimize, manage and book trips.

Users should be able to:

- Describe a trip using natural language.
- Discover destinations and attractions.
- Search real flights and hotels.
- Compare available prices.
- Check weather.
- Discover restaurants and activities.
- Generate realistic itineraries.
- Optimize routes and schedules.
- Manage budgets and expenses.
- Collaborate with other travellers.
- Manage bookings and travel documents.
- Replan when circumstances change.
- Complete bookings through authorized providers or booking handoffs.

Voyager also demonstrates modern AI engineering technologies through the actual travel-planning use case.

## 2.2 Two connected product dimensions

**Travel Workspace:** The actual travel application and primary user experience.

**AI Engineering Workspace:** A configurable environment for experimenting with models, agent frameworks, RAG, MCP, observability, evaluation, guardrails and other AI technologies.

These must not become disconnected demonstrations.

For example, a developer should be able to generate the same travel itinerary using LangGraph and CrewAI, using Ollama and OpenAI, and compare quality, latency, token usage, cost and execution traces.

## 2.3 Product principles

- Open-source-first.
- Local-first wherever practical.
- No mandatory paid API dependencies.
- Optional commercial AI providers.
- Preserve existing working functionality.
- Real integrations wherever access permits.
- Provider-independent architecture.
- Configurable and comparable integrations.
- Reproducible experiments.
- Transparent data sources.
- Explicit approval for financial actions.
- Strong security boundaries.
- Finite implementation phases.

This is a technically sophisticated portfolio and demonstration project, not an enterprise SaaS product.

Do not over-engineer it for imaginary enterprise scale.
